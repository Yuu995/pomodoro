# **不写一行代码，实现我的 Yes 工程师之路**

## 5.31

儿童节前，送自己一个快速创建待办事项的小工具

### 它有什么不一样？

其实没什么不一样，跟市面上很多待办工具不能说毫无相关，可以说是一模一样

### 为什么要做？

我尝试过很多方式记录todo list：电脑便签、IM 给自己发消息、随手打开空文档、花重金买的「things」APP

「things」APP真的很好用、很简洁、很符合我的诉求，甚至它还可以在 Mac 创建小组件，一眼知道今天要做什么、做完快速打勾...

但，上过班的都知道，桌面上的应用、浏览器已经把窗口都占满了，即便它已经轻便为小组件了，但我还是**找不到它**

对，**找不到这就是最大的痛点！** 不能便捷的找到 - 无法快速写上待办事项 - 难以建立使用依赖

所以，环顾桌面，只有**状态栏**是随时可以看到、操作的地方

于是，我的小工具诞生了~~

### 硬要说优势的话

- **轻轻 hover** 便能快速创建任务事项，桌面窗口堆满也不怕

- 什么重要、紧急判断优先级，都不如 **DDL 直观** ：「今天做完」「这周做完」「要做的事」

- **完成即撒花** 🎉 ！工作中的正反馈自己也可以给

## 功能一览

- ✅ **待办管理**：三档 DDL 优先级 —— 🟢 今天做完 / 🔵 这周做完 / ⚪️ 要做的；支持拖动排序、跨档调整，**完成即撒花** 🎉
- ⌨️ **键盘友好**：输入框聚焦后按 `↑` `↓` 直接切换优先级，回车保存
- 📅 **列表 / 日历两种视图**：日历里把任务拖到某天就排期了；已完成的任务会落在完成当天
- ✔️ **已完成**：按完成日期聚合，一眼回顾每天都做完了什么
- 🗑️ **回收站**：删除先进回收站，可随时恢复；超过 14 天自动清除
- 🧭 **状态栏常驻**：菜单栏一个 TODO 图标，**hover 即弹出**快捷面板并自动聚焦输入框，抬手就能记一条
- 🌗 **深色模式**：跟随系统，或手动切换浅色 / 深色
- 💾 **纯本地**：数据全部存在本地，离线可用、不上传

界面走 **Google AI Studio** 那种干净的纯白极简风：线性图标、浅灰圆角选中、克制的留白。

## 下载使用

到 [Releases](https://github.com/Yuu995/pomodoro/releases) 下载最新的 `TODO-x.x.x-arm64.dmg`，双击打开、把图标拖进「应用程序」即可。

> 目前为 Apple Silicon（arm64）构建，应用未做 Apple 付费签名 / 公证。

### 打开时提示「已损坏，无法打开」？

不是真的损坏，是 macOS Gatekeeper 在拦未签名的下载应用。把 app 拖进「应用程序」后，打开「终端」执行一行命令清除隔离标记即可：

```bash
xattr -cr /Applications/ToDo.app
```

> 不确定路径的话：终端先输入 `xattr -cr `（末尾留一个空格），再把 ToDo.app 图标拖进终端窗口（会自动补全路径），回车。之后双击即可正常打开。

### 升级会丢数据吗？

不会。数据锁定在固定目录 `~/Library/Application Support/tomato-clock/`，不随应用改名或升版本而变化 —— 装上新版本读的还是同一份数据。想更保险，升级前可以把这个文件夹复制一份备份。

## 本地开发

需要 Node.js。

```bash
npm install      # 安装依赖
npm start        # 本地运行
npm run dist     # 打包成 macOS dmg(产物在 dist/)
```

## 技术栈

Electron + 原生 HTML / CSS / JavaScript，无前端框架。数据全部存在本地 `localStorage`，纯离线、不上传。
