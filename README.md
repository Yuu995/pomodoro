# **不写一行代码，实现我的 Yes 工程师之路**

## 5.31

儿童节前，送自己一个快速创建待办事项的小工具

### 它有什么不一样？

其实没什么不一样，跟市面上很多待办工具不能说毫无相关，可以说是一模一样

### 为什么要做？

我尝试过很多方式记录todo list：电脑便签、IM 给自己发消息、随手打开空文档、花重金买的「things」APP

「things」APP真的很好用、很简洁、很符合我的诉求，甚至它还可以在 Mac 创建小组件，一眼知道今天要做什么、做完快速打勾...

但，上过班的都知道，桌面上的应用、浏览器已经把窗口都占满了，即便它已经轻便为小组件了，但我还是**找不到它**

对，**找不到这就是最大的痛点！** 不能便捷的找到 - 无法快速写上待办事项 - 难以建立使用依赖

所以，环顾桌面，只有**状态栏**是随时可以看到、操作的地方

于是，我的小工具诞生了~~

### 硬要说优势的话

- **轻轻 hover** 便能快速创建任务事项，桌面窗口堆满也不怕

- 什么重要、紧急判断优先级，都不如 **DDL 直观** ：「今天做完」「这周做完」「要做的事」

- **完成即撒花** 🎉 ！工作中的正反馈自己也可以给

---

## 功能一览

- 🍅 **番茄计时**：专注 / 短休 / 长休，自定义时长、声音提醒、完成统计与最近七日柱状图
- ✅ **待办 ToDo**：三档 DDL 优先级（今天做完 / 这周做完 / 要做的），拖动排序、跨档调整、完成撒花
- 🗑️ **回收站**：删除先进回收站，可恢复；超过 14 天自动清除
- 🧭 **状态栏常驻**：菜单栏番茄 / 待办图标，**hover 即弹出**快捷面板、自动聚焦输入框，失焦自动收起
- 🌗 **毛玻璃 + 深色模式**：macOS 原生毛玻璃；深色可跟随系统或手动切换
- 🖥️ 左侧任务栏（全部 / 已完成 / 回收站，可收起）；悬浮框只看当天，主窗口看全部

## 下载使用

到 [Releases](https://github.com/Yuu995/pomodoro/releases) 下载最新的 `番茄钟-x.x.x-arm64.dmg`，双击打开、把图标拖进「应用程序」即可。

> 首次打开若提示「来自身份不明的开发者」，右键点应用图标 → 打开。目前为 Apple Silicon（arm64）构建。

## 本地开发

需要 Node.js。

```bash
npm install      # 安装依赖
npm start        # 本地运行
npm run dist     # 打包成 macOS dmg(产物在 dist/)
```

## 技术栈

Electron + 原生 HTML / CSS / JavaScript，无前端框架。数据全部存在本地 `localStorage`，纯离线、不上传。
